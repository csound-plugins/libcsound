Csound API, version 6
=====================

This reference is valid for versions of csound >= 6.18 and prior to version 7.
The correct API is imported automatically based on the version of
csound installed in the system.

The API was reduced in csound 7. Some methods that set specific options were
removed; the same functionality is available through command-line options.
